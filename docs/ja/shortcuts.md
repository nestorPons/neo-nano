# キーボードショートカット

nnano は既定で**デスクトップ風キーマップ**を使います。衝突しない nano のキー割り当ては維持します。

**表記：** `Ctrl` = `^` · `Alt` = `M-`。macOS では `Alt` は `Option` で、`Cmd+*` はアプリに届きません。
*代替キー* 列は、存在する場合の nano 由来の割り当てです。

## ファイル

| 操作 | キー | 代替キー |
|---|---|---|
| 保存 | `Ctrl+S` | — |
| 名前を付けて保存 | `Alt+S` | — |
| ファイルを開く | `Ctrl+O` | — |
| ディスクから再読み込み | `Ctrl+R` | — |
| カーソル位置にファイルを挿入 | `Alt+I` | `Ctrl+R`（nano） |
| 新規バッファ | `Ctrl+N` | — |
| 新規タブ | `Ctrl+T` | — |
| バッファを閉じる | `Ctrl+W` | — |
| 終了 | `Ctrl+Q` | — |

## 移動

| 操作 | キー | 代替キー |
|---|---|---|
| 行へ移動 | `Ctrl+G` | `Alt+G` |
| 行頭 | `Home` | — |
| 行末 | `End` | `Ctrl+E` |
| 先頭行 | `Alt+\` | `Alt+\` |
| 最終行 | `Alt+/` | `Alt+/` |
| 単語単位で左 / 右 | `Ctrl+←` / `Ctrl+→` | `Alt+←` / `Alt+→` |
| 文字単位で選択範囲を拡張 | `Shift+←` / `Shift+→` | — |
| 行単位で選択範囲を拡張 | `Shift+↑` / `Shift+↓` | — |
| ページアップ | `PgUp` | `Alt+↑` |
| ページダウン | `PgDn` | `Alt+↓` |
| 1 文字戻る | `Ctrl+B` | `Ctrl+B` |

`Shift+←`/`Shift+→` は文字単位、`Shift+↑`/`Shift+↓` は表示列を保ったまま行単位で選択を拡張します（デスクトップエディタと同じ）。`Esc` で選択を解除します。選択中はどの移動も選択を拡張します（nano と同じ）。`Ctrl+C` はコピー後に選択を解除するので、続く `Ctrl+V` はカーソル位置に挿入します。

## 検索

| 操作 | キー | 代替キー |
|---|---|---|
| 検索 | `Ctrl+F` | — |
| 次を検索 | `F3` | `Alt+W` |
| 前を検索 | `Shift+F3` | `Alt+B` |
| 大文字小文字の切り替え（プロンプト内） | `Alt+C` | `Alt+C` |
| 正規表現の切り替え（プロンプト内） | `Alt+R` | `Alt+R` |

検索は nano と同じ挙動です：**インクリメンタル検索ではありません**（プロンプトを確定したときに実行）、既定はリテラル一致、既定は大文字小文字を区別せず、末尾まで到達すると先頭に戻って *検索が折り返されました* と表示します。
`Alt+R` はモーダルです：プロンプト内では正規表現の切り替え、プロンプト外では置換を開きます。

## インターフェース

| 操作 | キー | 代替キー |
|---|---|---|
| ヘルプ | `Ctrl+H` | `F1` |
| 設定メニュー | `Alt+,` | — |
| コマンドパレット | `Ctrl+P` | — |
| 構文ハイライトの切り替え | `Alt+Y` | `Alt+Y` |
| 画面を再描画 | `Ctrl+L` | `Ctrl+L` |
| 画面の言語 | `Alt+,` → 言語 | `--language <コード>` |

コマンドパレット（`Ctrl+P`）は各行の右側にそのコマンドのキーを表示し、キー名（`ctrl+q`）を入力してショートカットで絞り込むこともできます。ヘルプ（`Ctrl+H`）とパレットはキー入力を解釈する同じキーマップ表から生成されるため、動作しないキーを表示することはありません。

画面は 10 言語に対応しています：English、简体中文、हिन्दी、Español、العربية、Français、বাংলা、Português、Bahasa Indonesia、日本語。設定（`Alt+,` → 言語）または `--language ja` で選べます。`config.toml` の `language = "auto"` は `$LC_ALL`/`$LANG` に従います。

## ターミナルの制約

- `Ctrl+S` と `Ctrl+Q` は XON/XOFF フロー制御を無効にしないとターミナルに奪われます。
- `Enter`、`Tab`、`Backspace`、`Esc` は再割り当てできません。
- `Ctrl+B` は tmux の既定プレフィックス、`Ctrl+A` は screen のものです。
- `Ctrl+Shift+文字` は古いターミナルでは信頼できません。`Ctrl+Shift+Z` のやり直しはありません。
- ターミナル標準のテキスト選択は `Shift` を押しながらドラッグします。
- `mouse` オプションが有効なとき（既定）、nnano はマウスを使います：クリックでカーソル移動、ドラッグでマーク、`Alt`+ドラッグで矩形マーク、ホイールはカーソルを動かさずにスクロールします。右端のスクロールバーをクリックするとその位置へ移動します。 ボタンを離すと選択したテキストを内部レジスタとシステムのクリップボード（OSC 52）へコピーします。選択は別の場所をクリックするか `Esc` を押すまで残ります。
- ステータス行は `行:桁/総行数` を表示します：カーソル行、表示桁、文書全体の行数。
- 元に戻す単位：単語ごと、および 400 ms の停止で区切ります。切り取り・貼り付け・保存・バッファ切り替えで区切りが確定します。「すべて置換」は 1 ステップです。
- `Ctrl+H` でショートカット一覧を開きます。バックスペースは端末の Backspace キー（`0x7F`）です：端末が Backspace で `0x08` を送る場合、そのキーはヘルプを開きます。`0x7F` を送るよう設定してください。

## プロンプトとリカバリファイル

- `Alt+S` はパスを尋ねます。ファイル名のないバッファ（`nnano -`、新規バッファ、キャンセルされた名前を付けて保存）では `Ctrl+S` も尋ねます。*名前を付けて保存*、*開く*、*ファイルを挿入*では `Tab` がパスを補完します：候補が1つならそれで確定し、複数なら共通の接頭辞まで伸ばします。
- `Alt+S` は新しいファイルに書き込み、その名前を採用します。バッファバー、ステータスバー、構文ハイライトがそれに従います。書き込みに失敗した場合は元の名前のままです。
- `Alt+X` はその行を `sh -c` で実行し、標準出力をカーソル位置に1つのアンドゥ単位として挿入します。ステータスバーに終了コードと stderr の1行目が出ます。
- `Ctrl+R` はディスクからこのバッファのファイルを読み直してテキストを置き換えます。元のテキストのアンドゥ履歴は破棄されます。未保存の変更があるときは一度確認します（もう一度 `Ctrl+R` で再読み込み、`Ctrl+S` で保存）。
- `Alt+I` はファイルを尋ね、そのテキストをカーソル位置に1つのアンドゥ単位として挿入します。`Tab` がパスを補完します。バッファの名前とエンコーディングは変わりません。
- 未保存の変更があると、最後の編集から2秒後に `$XDG_STATE_HOME/nnano/recovery/` へリカバリスナップショットを書き込みます。クラッシュや切れた SSH セッションは次回起動時に自動で復元されます（`recovered unsaved changes for …`）。保存するか正常終了すると削除されます。
- `Ctrl+C` と `Alt+6` は常に内部レジスタへコピーします。`osc52` オプション（`--osc52`）を有効にすると、システムのクリップボードにも送ります（上限 64 KiB）。切り詰められた場合はステータスバーで通知します。コピーした量はステータスバーに表示され、レジスタが空のときの `Ctrl+V` はその旨を表示します。
- `Ctrl+J` はカーソルがある段落（またはマークした行）をテキスト領域の幅で折り返し直し、1行目のインデントを保ちます。1つのアンドゥ単位です。

# 键盘快捷键

nnano 默认使用**桌面风格键位**。与桌面习惯不冲突的 nano 键位予以保留。

**记法：** `Ctrl` = `^` · `Alt` = `M-`。在 macOS 上 `Alt` 是 `Option`；`Cmd+*` 不会传送到应用。
*替代键* 一列是继承自 nano 的按键（如果存在）。

## 文件

| 操作 | 按键 | 替代键 |
|---|---|---|
| 保存 | `Ctrl+S` | — |
| 另存为 | `Alt+S` | — |
| 打开文件 | `Ctrl+O` | — |
| 从磁盘重新加载 | `Ctrl+R` | — |
| 在光标处插入文件 | `Alt+I` | `Ctrl+R`（nano） |
| 新建缓冲区 | `Ctrl+N` | — |
| 新建标签页 | `Ctrl+T` | — |
| 关闭缓冲区 | `Ctrl+W` | — |
| 退出 | `Ctrl+Q` | — |

## 导航

| 操作 | 按键 | 替代键 |
|---|---|---|
| 跳转到行 | `Ctrl+G` | `Alt+G` |
| 行首 | `Home` | — |
| 行尾 | `End` | `Ctrl+E` |
| 第一行 | `Alt+\` | `Alt+\` |
| 最后一行 | `Alt+/` | `Alt+/` |
| 向左 / 向右一个词 | `Ctrl+←` / `Ctrl+→` | `Alt+←` / `Alt+→` |
| 按字符扩展选区 | `Shift+←` / `Shift+→` | — |
| 按行扩展选区 | `Shift+↑` / `Shift+↓` | — |

| 向下翻页 | `PgDn` | `Alt+↓` |

`Shift+←`/`Shift+→` 按字符扩展选区，`Shift+↑`/`Shift+↓` 按行扩展并保持视觉列，与桌面编辑器一致；`Esc` 取消选区。已有选区时，任何移动都会扩展它，与 nano 相同。 `Ctrl+C` 复制后会结束选区，因此接下来的 `Ctrl+V` 会在光标处插入。

## 搜索

| 操作 | 按键 | 替代键 |
|---|---|---|
| 查找 | `Ctrl+F` | — |
| 查找下一个 | `F3` | `Alt+W` |
| 查找上一个 | `Shift+F3` | `Alt+B` |
| 切换大小写敏感（提示框内） | `Alt+C` | `Alt+C` |
| 切换正则表达式（提示框内） | `Alt+R` | `Alt+R` |

搜索行为与 nano 一致：**不是增量搜索**（按确认后才执行），默认按字面匹配，默认不区分大小写，到达文件末尾后回绕并提示 *已回绕搜索*。
`Alt+R` 是模式相关的：在提示框内切换正则，在提示框外打开替换。

## 界面

| 操作 | 按键 | 替代键 |
|---|---|---|
| 帮助 | `Ctrl+H` | `F1` |
| 设置菜单 | `Alt+,` | — |
| 命令面板 | `Ctrl+P` | — |
| 切换语法高亮 | `Alt+Y` | `Alt+Y` |
| 刷新屏幕 | `Ctrl+L` | `Ctrl+L` |
| 界面语言 | `Alt+,` → 语言 | `--language <代码>` |

命令面板（`Ctrl+P`）在每一行右侧显示该命令的按键，输入按键（`ctrl+q`）也可以按快捷键过滤。帮助（`Ctrl+H`）和命令面板都由键盘解码所用的同一张快捷键表生成，因此不会显示无效的按键。

界面支持十种语言：English、简体中文、हिन्दी、Español、العربية、Français、বাংলা、Português、Bahasa Indonesia 和 日本語。可在设置（`Alt+,` → 语言）或 `--language zh-Hans` 中选择；`config.toml` 中的 `language = "auto"` 会跟随 `$LC_ALL`/`$LANG`。

## 与 nano 的区别

| 原按键（nano） | 现在 |
|---|---|
| `Ctrl+O` 保存 | `Ctrl+S` 保存 |
| `Ctrl+X` 退出 | `Ctrl+Q` 退出 · `Ctrl+X` 剪切 |
| `Ctrl+W` 搜索 | `Ctrl+F` 搜索 · `Ctrl+W` 关闭缓冲区 |
| `Ctrl+C` 光标位置 | 状态栏 · `Ctrl+C` 复制 |
| `Ctrl+V` 向下翻页 | `PgDn` / `Alt+↓` · `Ctrl+V` 粘贴 |
| `Ctrl+Y` 向上翻页 | `PgUp` / `Alt+↑` · `Ctrl+Y` 重做 |
| `Ctrl+A` 行首 | `Home` · `Ctrl+A` 全选 |
| `Ctrl+Z` 挂起 | 已移除 · `Ctrl+Z` 撤销 |
| `Ctrl+R` 插入文件 | `Alt+I` · `Ctrl+R` 重新加载 |
| `Ctrl+N` / `Ctrl+P` 下一行 / 上一行 | 方向键 `↓` / `↑` · 新建缓冲区 / 命令面板 |
| `Ctrl+T` 执行命令 | `Alt+X` · `Ctrl+T` 新建标签页 |
| `Ctrl+G` 帮助 | `F1` · `Ctrl+G` 跳转到行 |

保持不变：`Ctrl+K`、`Ctrl+U`、`Ctrl+E`、`Ctrl+D`、`Ctrl+J`、`Ctrl+L`、`Ctrl+B`、`Ctrl+\`、`Alt+U`、`Alt+E`、`Alt+A`、`Alt+6`、`Alt+G`、`Alt+\`、`Alt+/`、`Alt+W`、`Alt+B`、`Alt+C`、`Alt+R`、`Alt+Y`。

## 终端限制

- `Ctrl+S` 和 `Ctrl+Q` 需要关闭 XON/XOFF 流控制，否则会被终端吞掉。
- `Enter`、`Tab`、`Backspace`、`Esc` 无法重新分配。
- `Ctrl+B` 是 tmux 的默认前缀；`Ctrl+A` 是 screen 的默认前缀。
- `Ctrl+Shift+字母` 在旧终端上不可靠：没有 `Ctrl+Shift+Z` 重做。
- 要用终端自带的方式选择文本，拖动时按住 `Shift`。
- 开启 `mouse` 选项时（默认开启），nnano 使用鼠标：单击定位光标，拖动标记，`Alt`+拖动标记矩形，滚轮滚动而不移动光标；单击右侧的滚动条会跳到该位置。 松开按钮会把选中的文本复制到内部寄存器和系统剪贴板（OSC 52）；选区会保留，直到你在别处单击或按 `Esc`。
- 状态栏显示 `行:列/总数`：光标所在行、可视列以及文档总行数。
- 撤销分组：按单词和 400 毫秒停顿分组；剪切、粘贴、保存和切换缓冲区会结束当前分组。「全部替换」只算一步。
- `Ctrl+H` 打开快捷键参考。退格是终端的 Backspace 键（`0x7F`）：如果你的终端在按 Backspace 时发送 `0x08`，该键会打开帮助——请把它改成发送 `0x7F`。

## 提示行与恢复文件

- `Alt+S` 会询问路径；没有文件名的缓冲区（`nnano -`、新建缓冲区或取消的另存为）按 `Ctrl+S` 也会询问。在*另存为*、*打开*和*插入文件*中，`Tab` 补全路径：只有一个候选就填入，多个候选则补到公共前缀。
- `Alt+S` 写入新文件并采用其名称：缓冲区栏、状态栏和语法高亮都会跟随。写入失败时保留原来的名称。
- `Alt+X` 用 `sh -c` 执行该行，并把标准输出插入光标处，算一个撤销步骤；状态栏报告退出码和 stderr 的第一行。
- `Ctrl+R` 从磁盘重新读取本缓冲区的文件并替换文本；旧文本的撤销历史会被丢弃。有未保存的更改时询问一次（再按 `Ctrl+R` 重新加载，`Ctrl+S` 保存）。
- `Alt+I` 询问一个文件，并在光标处插入其文本，算一个撤销步骤；`Tab` 补全路径。缓冲区保留自己的名称和编码。
- 缓冲区有未保存的修改时，nnano 在最后一次编辑 2 秒后把恢复快照写入 `$XDG_STATE_HOME/nnano/recovery/`。崩溃或被中断的 SSH 会话会在下次启动时自动恢复（`recovered unsaved changes for …`）；保存或正常退出会删除它。
- `Ctrl+C` 和 `Alt+6` 总是复制到内部寄存器。开启 `osc52` 选项（`--osc52`）还会把副本发送到系统剪贴板，上限 64 KiB；截断时会在状态栏提示。状态栏会显示复制了多少内容；寄存器为空时按 `Ctrl+V` 会提示。
- `Ctrl+J` 把光标所在段落（或标记的行）按文本区域宽度重新排版，保留第一行的缩进。只算一个撤销步骤。
